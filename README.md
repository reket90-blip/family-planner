# Наш семейный планер

Личный планер для одного пользователя в формате PWA: календарь, дела, семейные даты, визиты к врачу, платежи, счётчики и ориентировочный календарь беременности.

## Текущий статус

- **PWA:** устанавливается на главный экран iPhone и открывается в отдельном окне.
- **Личный вход:** добавлен экран входа Supabase Auth; доступ к данным дополнительно ограничен приватным allowlist — без приглашения аккаунт не увидит и не изменит записи.
- **Облачное хранение:** события и настройки синхронизируются с отдельным Supabase-проектом; строки защищены RLS по владельцу.
- **Push:** развёрнута Edge Function, подписки сохраняются в БД, серверный cron запускается каждую минуту, VAPID и cron-секреты хранятся в Supabase Vault.
- **Требуется завершить запуск:** создать/пригласить единственного пользователя в Supabase Auth, отключить публичную регистрацию, включить push на реальном iPhone и проверить реальную доставку.
- **Репозиторий пока публичный:** в нём нет семейных записей или приватных ключей, но перед производственным использованием рекомендуется сделать его приватным.

## Разработка

Требуется Node.js 20+.

```bash
npm run check
npm test
npm run build
python3 -m http.server 8000
```

Для локального просмотра откройте `http://localhost:8000`. Service Worker работает только на HTTPS или localhost. Вход и синхронизация требуют интернета.

## Доступ и безопасность

Используется отдельный Supabase-проект `family-planner`, не база My Garage. В браузере находится только publishable key. Service-role key, VAPID private key и секрет расписания не хранятся в GitHub и находятся на серверной стороне.

1. В Supabase Authentication отключите **Allow new users to sign up**.
2. Создайте/пригласите только аккаунт жены в Authentication → Users.
3. Установите корректный Site URL и разрешённые redirect URLs для сайта планера.
4. Проверьте, что вход работает и чужой аккаунт не может читать чужие записи.
5. Не публикуйте медицинские/финансовые данные в issue, логи или репозиторий.

## Push-уведомления

Пользователь должен открыть планер на поддерживаемом устройстве, дать разрешение и включить уведомления в настройках. На iPhone нужно сначала добавить PWA на главный экран и запускать её с иконки (iOS/iPadOS 16.4+). Для событий без времени используется 09:00 в часовом поясе `Asia/Novosibirsk`. Сервис проверяет напоминания каждую минуту; реальную доставку нужно подтвердить на устройстве.

Техническая схема и настройки: `supabase/README.md`.

## Напоминания и календарь беременности

- Публичной регистрации нет: открой планер и войди в уже приглашённый аккаунт. Для восстановления доступа используй «Не помню пароль».
- В редакторе события есть **время события**, относительное напоминание (10/30/60 минут, день или неделя) и **отдельные дата и время напоминания**. Последние позволяют напомнить, например, записаться к врачу в выбранный день и час. Если задать отдельную дату без времени, используется 09:00 в часовом поясе Asia/Novosibirsk.
- Серверный cron проверяет сроки каждую минуту. Уведомления приходят только после входа и включения push на устройстве; в Настройках доступна кнопка **«Отправить тестовое уведомление»**.
- На iPhone/iPad нужно добавить PWA на экран «Домой», открыть именно установленное приложение и разрешить уведомления. Фактическую доставку подтверждай тестовой кнопкой на нужном устройстве.
- В разделе «Малыш» можно указать первый день последней менструации либо предполагаемую дату родов. Планер рассчитывает текущий срок, показывает недели с календарными датами и выводит текущую неделю на главный экран. Расчёт ориентировочный, не заменяет рекомендации врача.

# Наш семейный планер

Приватный семейный календарь в формате PWA: зелёный природный интерфейс, события, дела, даты семьи, визиты к врачу, платежи и ориентировочный календарь беременности.

## Текущий статус

- **UI-прототип:** реализован; данные пока сохраняются только локально в браузере.
- **PWA/offline shell:** манифест и service worker добавлены.
- **Безопасная схема облачного хранения:** подготовлена в `supabase/schema.sql`, с RLS и доступом только для владельца.
- **Облачная синхронизация, вход, Telegram и push:** ещё не подключены. Не считайте локальное сохранение облачной резервной копией.
- **Публикация:** не разворачивайте с реальными семейными данными, пока репозиторий публичный и не добавлены авторизация и серверная синхронизация.

## Разработка

Требуется Node.js 20+ (зависимостей сборки пока нет).

```bash
npm run check
npm test
python3 -m http.server 8000
```

Откройте `http://localhost:8000`. Не используйте `file://`: PWA service worker работает только на HTTPS или localhost.

## Следующие этапы

1. Сделать репозиторий приватным.
2. Создать отдельный Supabase-проект для планера — базу My Garage не использовать.
3. Применить SQL из `supabase/schema.sql`, создать только одну учётную запись и проверить RLS.
4. Подключить вход и облачную синхронизацию, включая перенос локальных событий.
5. Реализовать серверные Telegram/push-напоминания и проверить их на iPhone.
6. Пройти мобильные, доступностные, безопасность и резервное копирование проверки.

# Наш семейный планер — PWA

Первая мобильная версия в отдельном репозитории `family-planner`. Не меняет код Telegram-бота «Мой гараж».

## Что уже предусмотрено
- Адаптивный интерфейс под iPhone, зелёная природная тема.
- Разделы: сегодня, календарь, дела, дом и платежи, беременность.
- Создание/редактирование/удаление событий, отметка выполненного.
- Данные сохраняются локально на устройстве через localStorage; календарь работает без сети после первой загрузки.
- PWA-манифест, иконки и service worker.
- Дата начала беременности/ПДР с ориентировочным расчётом недели и триместра.

## Проверка локально
Откройте каталог в локальном веб-сервере (не через `file://`), например:
```bash
python3 -m http.server 8080
```
Затем откройте `http://localhost:8080/family-planner/`.

## Размещение
Нужен HTTPS. Для Render Static Site задайте Root Directory `family-planner`, Build Command `echo "Static PWA ready"`, Publish Directory `.`. После публикации откройте HTTPS-адрес в Safari на iPhone → Поделиться → На экран «Домой».

## Важно
Это MVP без серверной синхронизации и без надёжных фоновых уведомлений. Локальные данные пока привязаны к браузеру/устройству. Не храните здесь чувствительные медицинские подробности до подключения закрытой авторизации и серверной базы. Следующий этап: Supabase Auth + RLS, Telegram-напоминания через серверное расписание и Web Push для установленной PWA (iOS/iPadOS 16.4+).

## Важные ограничения
- Сейчас это прототип: данные хранятся только в браузере на одном устройстве и не синхронизируются между устройствами.
- Авторизация, Telegram-напоминания и серверные уведомления ещё не подключены.
- Не размещайте реальные семейные, медицинские или финансовые сведения в публичном демо. Перед использованием с настоящими данными сделайте репозиторий приватным и добавьте авторизацию и защищённое серверное хранилище.
